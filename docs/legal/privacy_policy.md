Reshet 개인정보처리방침

시행일: 2026년 9월 30일
문의: reshetcontact@gmail.com

Reshet는 성서 어휘와 단어 관계를 탐색하고 편집하는 앱입니다. 앱 사용을 위한 회원가입이나 로그인은 없으며, 광고·사용 분석·개발자 서버로의 자동 데이터 전송 기능을 사용하지 않습니다.

1. 앱에 저장되는 정보

사용자가 입력한 단어, 뜻풀이, 메모, 관계와 편집 이력은 기기의 앱 데이터베이스에 저장됩니다. 테마 등 일부 설정도 기기에 저장됩니다. 검색과 탐색 상태는 기능 제공을 위해 사용하며 개발자 서버로 전송하지 않습니다. 앱은 위치, 연락처, 카메라, 마이크 정보를 요구하지 않습니다.

2. 백업과 복원

사용자가 백업을 선택하면 전체 데이터베이스 파일을 사용자가 지정한 위치에 저장합니다. 복원은 사용자가 선택한 파일을 읽습니다. 제공 데이터로 전체 교체하기 전에는 현재 데이터의 백업 저장이 필요합니다.

백업에는 메모와 편집 이력 등이 포함되며 파일 자체는 암호화하지 않습니다. 사용자는 신뢰할 수 있는 위치에 보관하고 타인에게 전달할 때 포함 내용을 확인해야 합니다. 클라우드 저장 위치를 선택하는 경우 해당 서비스의 정책이 적용됩니다. 기기 운영체제의 백업·동기화 기능은 운영체제와 사용자 설정에 따라 적용될 수 있으며 Reshet 개발자가 해당 자료를 받는 것은 아닙니다.

3. 문의와 오류 제보

사용자가 이메일로 문의하거나 오류 자료를 보내면 이메일 주소와 자발적으로 제공한 내용은 문의 답변과 문제 해결에 사용합니다. 이메일 처리에는 이메일 서비스 제공자의 정책이 적용됩니다. 오류를 제보할 때 개인적인 메모나 전체 DB를 꼭 보낼 필요는 없습니다.

문의 자료는 처리에 필요한 동안 보관하고 목적 달성 후 삭제합니다. 법령상 보관 의무가 있는 경우에는 해당 기간을 따릅니다. 삭제 요청은 위 문의 주소로 보낼 수 있습니다.

4. 데이터 보관과 삭제

앱 데이터는 사용자가 편집하거나 제공 데이터로 교체할 때까지 기기에 보관됩니다. 앱 제거 시 앱 내부 데이터가 삭제될 수 있으므로 먼저 백업해야 합니다. 별도 위치에 저장한 백업이나 운영체제 백업은 앱 제거만으로 삭제되지 않을 수 있으며 사용자가 해당 위치에서 관리해야 합니다.

5. 테스트 대상과 변경 안내

이번 비공개 테스트는 성인 사용자를 대상으로 합니다. 데이터 처리 방식이 변경되면 이 방침을 갱신하고 필요한 안내를 제공합니다.
