## 비고

**H0202**

힘과 기력을 나타내며, 장자·생식 능력의 문맥과 하나님의 큰 힘에도 쓰인다. 욥 20:10과 호 12:9(일반 12:8)에서는 재물을 가리킨다. H3581·H6109와 구별하여 번역할 때 기력·기운을 우선 검토하되, 이 표현들이 H202만의 배타적 의미는 아니다. Strong은 H205와 같은 기반일 가능성을 제시하지만 BDB는 별도 어근군으로 구별한다. H1952와는 재물 뜻이 유사하나 직접 파생이나 단순 이형으로 확정하지 않는다. 잠 11:7은 현재 OSHB에서 H205로 태깅되지만 BDB에는 H202의 힘 해석이 있다.

**H0203**

민 16:1에 나오는 르우벤 자손 벨렛의 아들이다. 같은 한국어 이름으로 적는 이집트 지명 온(H0204)과 구별한다.

**H0204**

창 41:45, 41:50, 46:20에 나오는 이집트 도시로, 보디베라가 이곳의 제사장으로 언급된다. Strong은 이집트어 기원으로 설명한다. 로컬 사전의 H0202와 같은 어원이라는 설명은 이와 충돌하므로 채택하지 않는다. 겔 30:17의 아웬(H0206)과 관련해 참조되지만 이 참조 자체가 어원 관계를 뜻하지는 않는다.

**H0205**

고통과 해악, 악한 행위, 헛됨과 우상적 대상에 걸쳐 쓰이며 문맥에서 서로 겹칠 수 있다. Strong의 사용되지 않는 어근에 대한 설명은 추정이다. BDB는 H202와 별도 어근군으로 구별하고 H8383을 같은 군에 둔다. H5999와의 고통·수고 문맥 병행은 의미상의 연결이다. 잠 11:7의 אוֹנִים은 OSHB의 H205 태그와 BDB의 H202 해석이 다르다. H1007·H1126 같은 이름에서는 해당 구성과 문맥에 맞추어 뜻을 풀이한다. 신 26:14와 호 9:4에서는 상중의 슬픔, 사 66:3에서는 우상을 가리킨다. 호 10:8은 OSHB에서 H0205로 태깅하지만 지명 아웬으로 읽는 해석을 H0206·H1007 문맥과 함께 보존하며 태그를 임의로 옮기지 않는다.

**H0206**

Strong은 이 이름을 세 장소에 쓰인 경멸적 호칭으로 설명한다. 현재 OSHB의 H0206 출현은 겔 30:17과 암 1:5의 2회이며, 호 10:8은 H0205로 분류한다. 겔 30:17의 이집트 온과 암 1:5의 아웬 골짜기를 같은 장소로 합치지 않는다. H0204·H1007을 보라는 사전 참조를 파생 관계로 바꾸지 않는다.

**H1007**

벧아웬은 개역 계열의 관용 표기이고, 베트-아웬은 בֵּית와 אָוֶן의 합성 경계를 보인 분석 표기이다. 특정 시대의 실제 발음을 확정하지 않는다. 여호수아·사무엘상의 지리 문맥 4회와 호세아의 벧엘을 비꼬는 문맥 3회를 구분하며, 모든 벧아웬을 벧엘과 같은 장소로 처리하지 않는다. 이름의 헛됨·죄악 관련 뜻풀이는 지명 자체의 독립 의미로 늘리지 않는다.

**H1126**

베노니는 한국어 성경 관용 표기이고, 벤-오니는 בֶּן과 אוֹנִי의 경계를 보인 분석 표기이다. 창 35:18에서 죽어 가는 라헬이 아들에게 붙인 이름이며, 아버지는 베냐민이라 부른다. Strong과 문맥은 나의 슬픔의 아들이라는 풀이를 뒷받침한다. 합성 관계의 둘째 요소는 H0205로 제시되며, 모양이 비슷하다는 이유로 H0202로 바꾸지 않는다.

**H1951**

신 1:41의 Hiphil 활용형에서 산지로 올라가는 일을 쉽게 여기는 뜻으로 사용된다. 경솔하게 나아갔다는 문맥 해석과 KJV의 준비되었다는 풀이를 구분한다. Strong과 BDB는 H1952와 연결하지만, 재물이 삶을 쉽게 한다는 의미 발달 설명은 가설이다.

**H1952**

재물을 뜻하며 잠 30:15–16에서는 충분하다·족하다는 감탄적 표현에 사용된다. 시 44:13(일반 44:12)에서는 매매 대가의 문맥이다. Strong은 H1951과 같은 기반을 제시하고 H202의 재물 뜻을 참조한다. 공통 기반이라는 사전적 분류와 구체적인 의미 발달 가설을 구분하며, H202의 직접 파생어 또는 단순 철자 변이로 확정하지 않는다.

**H8383**

Strong은 H205에서의 파생으로 설명하고 BDB도 같은 어근군에 둔다. 겔 24:12에는 복수형 תְּאֻנִים만 나타나며, 제거되지 않는 녹을 둘러싼 수고의 문맥이다. 헛수고는 문맥 풀이로 볼 수 있다. KJV는 거짓으로 옮기며, 문장 해석과 본문 상태에 이견이 있어 의미를 과도하게 확정하지 않는다. Strong의 단수 표제어와 실제 복수 활용형을 구별한다.

## 채택하지 않은 대안과 불확실성

- H202의 meaning은 힘/재물로 유지한다. 기력·기운은 구별 번역의 우선 후보이며 별도 sense로 늘리지 않는다. 사 40:29의 번역 초안은 H3581 힘 / H202 기력 / H6109 능력으로 구별하지만 원어의 배타적 의미 차이를 주장하지 않는다.
- H202–H205 어원 관계 생성은 보류한다. Strong의 probably와 BDB의 별도 어근군을 모두 보존한다. H202–H1952는 재물 뜻의 의미 유사 관계이며 직접 파생·variant는 승인하지 않는다.
- H1951–H1952의 공통 기반은 유지하되 재물이 삶을 쉽게 한다는 의미 발달 경로는 가설이다. H205–H8383의 파생 관계는 H205의 모든 뜻을 상속한다는 의미가 아니다.
- H205의 앞선 의미별 64/10/3/1/1 분류는 확정 통계로 사용하지 않는다. 잠 11:7의 OSHB H205 태그와 BDB H202 해석 차이를 비고에 반영하며 정본 태그는 바꾸지 않는다.
- H8383의 수고를 우선하지만 거짓 풀이와 본문비평·통사 이견을 비고에 남긴다. 새 semantic hold는 없고 기존 hold ledger는 변경하지 않는다.
- H6109의 사 47:9·나 3:9 분석 차이는 외부 연구에 보존한다. 해당 비교 어휘의 의미·형태·태그를 이번 승인으로 변경하지 않는다.
