- H4928의 호위대는 왕실 문맥의 번역이고 사 11:14는 복종을 가리킨다. H8088과 H8089는 들은 소식·평판을 공유하며, 창 29:12–13은 직접 전언이다. H8088의 듣는 행위와 악기 소리는 별도로 등록했다.
