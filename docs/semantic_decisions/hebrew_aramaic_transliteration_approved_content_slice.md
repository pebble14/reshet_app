## 최종 결정과 범위

Reshet의 한글 음역은 사용자가 배우는 교재 전통을 기준으로 원어의 소리를 근사한다. 이 결정은 티베리아 발음이나 기록 당시 실제 발음을 일괄 복원하라는 승인이 아니다. Strong의 로마자 전사·영어식 발음 안내는 비교 근거이며, 원어의 모음·형태와 충돌할 때 자동 정답으로 삼지 않는다. 한글 외래어 표기 규정에 맞추는 것보다 소리를 한글로 기록하려는 사용자의 목적을 우선한다.

처음 승인한 음역 14건, 비교 사전과 맞춘 원어 16건, 피드백으로 승인한 65개 expression, 마지막 H0000_0015 / 2의 재수정을 합쳐 최종값을 기록한다. H0000_0015 / 2는 중간에 `호쉬아나`를 적용했지만 사용자가 음역 항목의 목적을 다시 확인하여 **호쉬안나**로 확정했다. 아래 표는 최초 적용 전 값과 이 최종값을 비교한다. 동일 필드의 중간 변경은 최종 건수에 중복 합산하지 않는다.

첫 적용은 피드백에 직접 등장한 항목을 중심으로 95개 expression에 한정됐으나, 사용자의 “나머지는 네 제안에 따라 적용한다”는 지시를 충분히 반영하지 못했다. 이후 기존 전체 보고서와 승인 범위를 대조하여 구체적인 음역 제안 264건의 반영 누락을 복구했다. 당시 조건부로 남겼던 22개는 별도 보고서를 검토한 사용자의 전체 승인에 따라 19개 expression을 수정하고 3개는 모든 값을 유지했다. 첫 적용분·추가 복구분·조건부 최종 승인분을 아래에 구분한다. 의미·비고·언어·Strong 번호·관계·lookup·원자료 보관 자료·DB schema·배포용 seed·앱 코드는 변경하지 않았다. Git 제외 작업 DB는 로컬에 보존하며 DB 파일을 저장소에 추가하지 않는다. 상설 실행 도구나 자동 치환 규칙을 추가하지 않았다.

이후 원어·발음 전수 대조와 사용자 피드백에 따른 최종 통합안 2,046개 expression을 별도로 승인받아 반영했다. 이번 추가분은 원어 1,343건·발음 589건·한글 음역 286건이다. 앞선 적용분과 겹치는 필드는 최초 변경 전 값과 최신값으로 합쳐 위 누적 수를 계산했다. 아래 초기 적용·복구 표는 당시 승인값을 보존하는 이력이며, 후속 변경된 필드의 최신 기준은 마지막 「원어·발음 전수조사 최종안 적용」 절과 해당 누적 승인 JSON이다.

## 주요 표기 판단

- **셰와**: 유성·묵음을 위치와 형태, 교재의 강세 규칙에 따라 개별 검토했다. 모든 셰와를 하나의 한글 모음으로 바꾸지 않는다. 첫 14건의 `샵베타이·쇼메론` 등을 포함해 승인된 개별값만 적용했다.
- **카마츠**: H1315는 첫 a를 남겨 `바세마트`, H7133·H7144·H7145는 카마츠 카탄 o를 반영해 `코르반·코르하·코르히`로 기록했다. H2653의 `하파프`는 유지했다.
- **H1973**: 최종값은 `할라`다. 앞선 `할아` 우선 제안은 정정했다. 묵음 셰와를 전제한 원어의 `할-아` 분절을 한글 표기에 직접 강제하지 않는다. `할라`의 ㄹㄹ은 라메드의 l 소리를 살리는 한글 근사로 볼 수 있으며, 히브리어에 겹자음 לּ가 있다는 뜻은 아니다. Strong의 유성 셰와 안내에 따른 `할레아`는 이 항목의 최종 채택값이 아니다.
- **다게쉬**: 레네와 포르테를 구분했다. H4660 `맢파츠`, H2646 `훞파`, H6977 `케웇차`, H8339·H8340 `셰쉬밫차르` 등은 사용자가 원하는 자음 표기를 반영한다. 점의 모양이 같다는 이유로 모든 자음을 겹치지 않는다.
- **H1912**: 사용자가 최종 지정한 문자열 `혿두`를 채택했다. 원어는 빠진 다게쉬를 복구한 הֹדּוּ다. 지정한 한글값을 승인 기록으로 보존하며, 이 선택을 원어 첫 모음의 새로운 판독이나 다른 단어의 일반 규칙으로 확대하지 않는다. 기존 발음란 `Hoddu`는 그대로다.
- **H5464**: 최종 원어는 סַגְרִיר, 발음란은 `sagrîr`, 한글은 `사그리르`다. 잠언 27:15의 סַגְרִ֑יר에 따라 마지막 dalet ד를 resh ר로 보정했다. samekh ס는 s이므로 `샤그리드`를 채택하지 않았다. 기존 발음 `sagrir`의 i에 장모음 표시를 보완했으며 한글 `사그리르`는 유지했다. 발음 방식 metadata는 기존값을 보존했고 이 값을 IPA로 분류하지 않았다.
- **와우**: H4200은 w 독법에 따라 `메제우`를 채택했다. `우`는 끝의 자음 w를 한글로 풀어 쓴 근사다. H5773 `아우에`, 유지한 H2058 `와프시`와 같은 읽기 선택이다. H4200의 기존 발음 안내 `meh'-zev`는 Strong의 v 독법 자료로 남겼다.
- **H0000_0015 / 2**: 최종 음역은 **호쉬안나**다. `호쉬아 + 나`라는 구성 분석과, 원문의 연결 다게쉬 נּ를 반영하는 음역을 구분한다. 사용자는 이번 필드가 음역이라는 이유로 겹자음을 반영하는 안을 최종 선택했다. /2의 원어는 보존했다. 후속 조건부 승인에서 /1은 짧은 명령형 הוֹשַׁע נָא를 유지하고 음역을 **호샤 나**로 보정했다. /1과 /2를 같은 형태로 통합하지 않았다.
- **e와 ei**: 교재별 차이가 있을 수 있으나 이번 기본값은 기존 단모음 기록을 유지했다. H1020의 `베트 하예쉬모트`, H0000_0005의 `벹 하스다`, H0000_0006의 `베트 아느야`, H0000_0010의 `베트 차이다`를 `베이트`로 일괄 변경하지 않았다. H3916은 `렐레야`로 채택했다.
- **원어·형태 우선**: 복수형 안내를 현재 단수 expression에 가져오거나 없는 마지막 모음을 추가하지 않았다. H0000_0041의 모음 없는 어근 ל־א־ך에는 새 발음을 만들어 넣지 않고 음역 공란을 보존했다.
- **필드 경계**: 조건부 22개까지 발음란 변경은 누적 7건이었다. 후속 전수 대조 승인에서 발음 589건을 추가하되, 그중 H4586은 기존 승인 필드의 재변경이므로 누적 고유 발음 변경은 595건이다. 원어의 현재 형태와 발음 안내를 대조했으며, 발음 체계 자체를 하나로 통일하지 않았다. 근거가 없는 사용자 항목의 발음 공란 36건과 기존 사용자 발음 6건은 유지했다.
