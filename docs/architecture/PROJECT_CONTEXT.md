# PROJECT_CONTEXT.md

## 프로젝트 이름

Reshet


## 프로젝트 목적

Reshet은 **단어 사이의 관계를 탐색하기 위한 그래프 기반 도구**이다.

특히 성경 원어(히브리어 / 헬라어 등) 단어 사이의 관계를
네트워크 형태로 탐색할 수 있도록 설계된 프로그램이다.

이 프로젝트의 핵심 목표는

> 단어의 의미를 관계 네트워크 속에서 이해하는 것이다.


---

# 핵심 개념

Reshet은 단어를 단순한 사전 항목이 아니라
**서로 연결된 네트워크 노드**로 본다.

그래프를 통해 다음 질문에 답할 수 있다.

- 어떤 단어가 어떤 단어와 연결되는가
- 단어 사이의 관계 구조는 무엇인가
- 특정 단어를 중심으로 어떤 의미 네트워크가 형성되는가


---

# 기술 스택

이 프로젝트는 다음 기술을 사용한다.

- Flutter
- Dart
- SQLite


---

# 데이터 구조

단어 데이터는 SQLite 데이터베이스에 저장된다.

주요 테이블:

```text
WORD_TABLE
WORD_RELATION
```


---

## WORD_TABLE

단어 자체의 정보를 저장한다.

예:

- id
- 언어
- 스트롱넘버
- 표기1
- 음역
- 발음
- 의미
- 비고

---

## WORD_RELATION

단어 사이의 관계를 저장한다.

예:

- word_id_1
- word_id_2
- relation_type
- category_code

이 테이블이 **그래프 구조의 핵심 데이터**이다.

그래프는 반드시 WORD_RELATION을 기반으로 생성한다.


---

# 그래프 구조

그래프는 **중심 단어 기반 Ego Network** 구조를 사용한다.

즉 항상 하나의 중심 단어가 존재한다.

```text
  word
   │

─── center ───
│ │ │
word word word
```


중심 단어와 직접 연결된 단어들이 주변 노드로 표시된다.

그래프 구조 규칙은 다음 문서에 정의되어 있다.

```text
GRAPH_ENGINE_RULES.md
```

---

# 핵심 화면

그래프 기능의 핵심 화면은 다음 파일이다.

```text
lib/ui/word_graph_screen.dart
```


이 화면은 다음 기능을 담당한다.

- 중심 단어 표시
- 연결 단어 노드 표시
- 노드 원형 배치
- 노드 간 관계선 표시
- 노드 클릭 탐색


---

# 데이터 접근 구조

데이터 접근은 다음 구조를 따른다.

```text
UI
↓
Repository
↓
DatabaseService
↓
SQLite
```


즉 UI 코드에서 SQL을 직접 작성하지 않는다.

데이터 조회는 Repository 계층을 통해 이루어진다.

주요 데이터 모델:

# 그래프 탐색 방식

그래프 탐색은 다음 방식으로 이루어진다.

```text
노드 클릭
↓
선택 노드가 새로운 중심 단어
↓
WORD_RELATION 조회
↓
그래프 재구성
```


이 방식으로 단어 관계 네트워크를 탐색할 수 있다.


---

# 현재 개발 단계

현재 Reshet 프로젝트는 다음 단계에 있다.

- 데이터베이스 연결 완료
- 단어 목록 화면 구현
- 단어 상세 화면 구현
- 그래프 화면 구현
- WORD_RELATION 기반 그래프 표시 구현

현재 그래프는 **1단계 관계(Level 1)** 를 표시한다.

```text
center word
│
├── connected word
├── connected word
└── connected word
```

# AI 작업 시 주의사항

AI 도구(Codex 등)는 다음 규칙을 따른다.

1. AGENTS.md 규칙을 따른다.
2. lib/AGENTS.md의 Flutter 코드 규칙을 따른다.
3. 그래프 구조는 GRAPH_ENGINE_RULES.md를 따른다.
4. 코드 수정 전 반드시 관련 파일을 확인한다.
5. 사용자 승인 없이 코드를 수정하지 않는다.

# 프로젝트 철학

Reshet의 핵심 철학은 다음과 같다.


단어는 관계 속에서 이해된다.


이 프로젝트는 단어를
**고립된 의미 단위가 아니라 관계 네트워크의 일부**로 탐색할 수 있도록 설계된다.
